# مرجع تصميم موقع نَمَط

هذه النسخة هي مرجع التصميم والمحتوى المعتمد بتاريخ 2026-10-03.

- افتح `index.html` في المتصفح مع إبقاء مجلد `assets` بجانبه.
- `assets/namat-theme.css` و`variables.css`: الألوان وشكل البطاقات.
- `assets/motion.css` وJavaScript داخل الصفحة: الحركات وتبديل صور البطاقة.
- `NAMAT-website-design.zip`: النسخة الكاملة للتنزيل.
- `design-reference`: مرجع التصميم الأصلي؛ الصفحة وملفات assets هي المرجع النهائي بعد التعديلات.

## تعليمات Cursor

استخدم هذا المجلد كمرجع لتطبيق التصميم على الموقع الحالي، مع الحفاظ على وظائف التطبيق والشراء والتوافق. التصميم عربي RTL ومتجاوب، بخلفية داكنة وصور قابلة للتبديل على البطاقة. هذه نسخة واجهة ثابتة للعرض، وليست تطبيق iOS أو ربطًا بخدمات الدفع.
